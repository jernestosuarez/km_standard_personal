# correction notes/ (optional)

When the Reader spots a defect (a stale fact, a broken link, a contradiction), it notes it in one line
and carries on answering the question it was asked. If the owner wants those notes carried back to a
build session, write them here, one file per reading session. This area is optional; a Reader that is
not asked to hand defects back does not need it.

The Reader does not investigate, design a fix, or open the machinery. Noting a defect is complete; the
next build session picks it up.
