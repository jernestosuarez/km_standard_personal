# Archive

Retired narrative docs. Kept for the audit trail — never deleted.

A doc lands here when it no longer describes anything current: superseded strategy notes, closed
workstreams, plans overtaken by events. It stays readable and stays in git; it is excluded from
generated artifacts so it stops competing for attention.

Retirement is a normal act. A doc whose conditions expired was not wrong — it aged. A hub that has
never archived anything is not well-maintained, it is unexamined.
